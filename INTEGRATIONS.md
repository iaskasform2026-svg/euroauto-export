# Intégrations

| Source | Statut | Commentaire |
|---|---|---|
| Import manuel (formulaire) | Opérationnel | Saisie contrôlée, détection de doublons par empreinte |
| Import CSV / JSON partenaire | Opérationnel | Séparateur `;` — voir écran admin Import |
| Stripe Checkout + webhook | À connecter (mode test prêt) | Confirmation uniquement par événement signé |
| SMTP (e-mails) | À connecter | Sans SMTP, aucun e-mail n’est marqué « envoyé » |
| AutoScout24 API | À connecter | Accès partenaire requis |
| Mobile.de API | À connecter | Accès partenaire requis |
| Leboncoin | Manuel / partenariat | Pas d’API publique adaptée — pas de scraping |
| Autres sites protégés | Non automatisés | Import manuel ou contrat d’accès uniquement |

Les exigences fiscales / douanières sont des `RegulatoryRule` datées. Une règle `A_VERIFIER` n’est jamais présentée comme obligation certaine.
